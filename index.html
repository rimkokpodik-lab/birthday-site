Отправьте дату рождения преподавателю

Данные уходят на сайт обычным .txt-файлом. Преподаватель скачивает ваш файл из своего кабинета.

  1. Скачайте файл otpravka.bat — внутри уже прописан адрес этого сайта.
    ⬇ Скачать .bat
  2. Запустите его двойным щелчком. В чёрном окне введите ФИО, группу и дату рождения в формате ДД.ММ.ГГГГ.
  3. Готово. Файл с вашими данными появится в кабинете преподавателя, а вы увидите сообщение об успехе.
Адрес приёма: —

Для программ: POST на этот адрес, тело запроса — текст файла (UTF-8). Заголовок X-Filename необязателен.

Отправить из кода (curl / PowerShell / Python)

Все примеры отправляют на —

curl

curl -X POST -H "Content-Type: text/plain; charset=utf-8" --data-binary @birthday.txt ".../api/upload"

PowerShell

$body = [IO.File]::ReadAllBytes("birthday.txt")
$wc = New-Object Net.WebClient
$wc.Headers.Add("X-Filename", "birthday.txt")
$wc.UploadData(".../api/upload", "POST", $body)

Python

import urllib.request

data = open("birthday.txt", "rb").read()
req = urllib.request.Request(
    ".../api/upload",
    data=data,
    headers={"Content-Type": "text/plain; charset=utf-8",
             "X-Filename": "birthday.txt"},
)
print(urllib.request.urlopen(req).read().decode("utf-8"))
